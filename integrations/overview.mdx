### Communication

- **Slack** - Notifications and approvals
- **Microsoft Teams** - Approval workflows
- **Email** - Invoice ingestion and notifications

### SSO & Identity

- **SAML 2.0** - Enterprise SSO
- **Azure AD** - Microsoft identity
- **Okta** - Identity management
- **Google Workspace** - Google SSO

## Integration Methods

### 1. Native Integrations
Pre-built connectors where available (e.g. NetSuite). Other systems are connected through file exchange (IDoc, export files) or API/SFTP/AS2, configured per project.

### 2. REST API
Full API access for custom integrations.
[View API Reference](/api-reference/introduction)

### 3. Webhooks
Real-time event notifications.
[Configure Webhooks](/integrations/webhooks)

### 4. MCP Servers
Model Context Protocol for AI tools.
[MCP Documentation](/integrations/mcp/overview)

## Getting Started

1. Navigate to **Settings > Integrations**
2. Select the integration you want to configure
3. Follow the setup wizard
4. Test the connection
