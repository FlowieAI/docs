## AI-Powered E-Invoicing

Upload invoices in **any format** - PDF, images, or electronic standards. Flowie uses LLM-based extraction mapped to EN 16931 fields, with human review for low-confidence fields.

## Supported Formats

### Unstructured (AI Extraction)

| Format | Processing |
|--------|------------|
| **PDF** | OCR + Vision AI |
| **Images** | OCR + Vision AI |
| **Office** | Text + AI |

### Structured (Direct Parse)

| Standard | Region |
|----------|--------|
| **PEPPOL BIS 3.0** | EU |
| **UBL 2.0/2.4** | Global |
| **Factur-X** | France |
| **SAP IDOC** | Enterprise |

## Quick Example

```bash
# Upload an invoice
curl -X POST https://back.p2p-flowie.com/doc/organizations/{org_id}/documents \
  -H "Authorization: Bearer YOUR_TOKEN" \
  -F "file=@invoice.pdf"
```

**Extracted data:**

```json
{
  "documentType": "INVOICE",
  "confidence": 0.94,
  "vendor": {
    "name": "Acme Corp",
    "vatNumber": "FR12345678901"
  },
  "amounts": {
    "net": 1000.00,
    "tax": 200.00,
    "gross": 1200.00
  },
  "lineItems": [...]
}
```

## AI Extraction

LLM-based extraction mapped to EN 16931 fields; human review for low-confidence fields.

## Base URL

| Environment | Base URL |
|-------------|----------|
| Production | `https://back.p2p-flowie.com` |
| Sandbox / staging | `https://back.flowie.ink` |

The Exchange API (e-invoicing send/receive, directory, lifecycle) is served under the `/exchange` prefix, e.g. `https://back.p2p-flowie.com/exchange/v1/...` (sandbox: `https://back.flowie.ink/exchange/v1/...`).
